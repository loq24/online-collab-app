# Online Collab App ✨

A real-time document collaboration platform built with Next.js that enables teams to work together seamlessly.

## ⚡ Features

- Real-time document editing
- Live collaboration with multiple users
- Comment threads and discussions
- Role-based access control (Editor/Viewer)
- Modern rich text editor interface
- Document sharing and permissions management

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Liveblocks
- Sentry for monitoring
- Clerk for authentication

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Set up environment variables
4. Run the development server:

```bash
npm run dev
```
